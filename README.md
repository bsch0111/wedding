## 📷 사진 폴더 안내

사진은 **용도별 폴더**로 나눠서 관리합니다. 아래 폴더에 사진만 바꿔 넣으면 청첩장에 반영됩니다.

```
assets/
├── cover/     ← 표지(첫 화면) 사진   · 1장   (파일명: 01.jpg)
├── journey/   ← 여정 사진            · 3장   (01.jpg, 02.jpg, 03.jpg · 순서대로)
├── gallery/   ← 갤러리 사진          · 여러 장 (01.jpg, 02.jpg, 03.jpg …)
└── gif/       ← GIF 파일 넣는 곳     (선택)
```

| 폴더 | 청첩장 위치 | 넣는 사진 | 개수 |
|------|-------------|-----------|------|
| `assets/cover/`   | 맨 처음 표지 배경 | 대표 사진 | 1장 (`01.jpg`) |
| `assets/journey/` | "두 사람이 걸어온 길" | 스토리 사진 | 3장 (`01`,`02`,`03`) |
| `assets/gallery/` | "우리의 순간들" 갤러리 | 모아보기 사진 | 여러 장 (`01`,`02`…) — `01`이 맨 위 큰 사진 |

**🖼 사진 고르기 도구** — `사진고르기.html` 을 더블클릭하면 `result/` 사진 전체를 한눈에 보며 표지·여정·갤러리로 골라 담을 수 있습니다. 다 고른 뒤 "고른 사진 복사"를 눌러 결과를 전달하면 각 폴더에 넣어 드립니다. (선택은 자동 저장됩니다.)

**사진 바꾸는 법**: 원하는 사진을 해당 폴더에 넣고 이름을 `01.jpg`, `02.jpg` … 순서로 맞춘 뒤 브라우저 새로고침(⌘R). 개수·파일명을 자유롭게 쓰려면 HTML 맨 위 `CONFIG`의 목록만 수정하면 됩니다.

**⚠️ 방향 주의**: 휴대폰/카메라 사진은 회전정보(EXIF) 때문에 표지 배경에서 옆으로 눕기도 합니다. `result/`의 원본 사진들은 이미 **똑바로 세우고 용량을 줄여** 각 폴더에 넣어 두었습니다(원본 고화질은 `result/`에 그대로 보관). 새로 넣은 사진 방향이 이상하면 알려주세요.
